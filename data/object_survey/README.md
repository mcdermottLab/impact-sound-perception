# Everyday-object survey

These files were supplied by James Traer for the accompanying paper.

- `Mturk_survey_batch_results_anon.csv`: 100 survey responses. Recruitment-platform
  worker and assignment IDs were removed before the file was supplied. The
  shared file is retained without further edits.
- `ObjectSurvey-Jan2020-summary.xlsx`: James's summary of repeated object reports,
  grouped by material and size.

Response columns `Answer.01-lt10cm`, `Answer.02-10-30cm`, `Answer.03-30-100cm`,
`Answer.04-1m-3m`, and `Answer.05-gt3m` contain object reports in five size ranges.
`Answer.06-loc` records the location response. Other columns retain survey-task
and timing information from the anonymized export. The workbook preserves the
original summary layout.

These are object-survey data, separate from the sound-perception participant
arrays in `Human_Experiments/`.
